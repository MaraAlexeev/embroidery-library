A swirling composition of amber, blue, aqua, navy and teal ribbons.
Machine file: ns_zigzag_1.pes. Editable source: ns_zigzag_1.svg.
Brother Skitch PP1; 4 x 4 inch / 100 x 100 mm hoop; PES version 1.
Finished needle bounds: 80.1 x 92.1 mm. One hooping. Six thread-loading steps.

TESTING STATUS — SUCCESSFUL SEW-OUT REPORTED
The owner reported successfully sewing this file on November 11, 2026,
and explicitly requested that the original machine file be preserved.
The precise fabric, thread and stabilizer of that sew-out were not recorded.
The downloadable PES is byte-for-byte identical to that original file.
This is not a repaired or newly digitized version.

The original contains tightly repeated anchoring drops and trim-marked travel
at its initial start and color entries. Those commands are deliberately
retained to preserve the successfully sewn file. They can behave differently
with another fabric or machine setup. Test on stabilized scrap first.
The original preview is a software simulation, not a sew-out photograph.

SIZE AND COUNTS
Readback of the actual PES: 9,147 sewing points; 74 trim commands;
75 positioning jumps; five color changes / six thread-loading steps.
The original production worksheet reports 8,875 design stitches and 28 trims.
Its pre-export counts differ from the encoded PES, which includes additional
anchor and travel commands. The PES readback is used for this public package.
